   - Replace `<Stack screenOptions={{ headerTitle: "Cookbook" }} />` with:
   ```typescript
   <Stack screenOptions={{ headerShown: false }}>
     <Stack.Screen name="(tabs)" />
     <Stack.Screen name="(auth)" />
     <Stack.Screen name="(public)" />
     <Stack.Screen
       name="(scan)"
       options={{ presentation: "modal", headerShown: false }}
     />
   </Stack>
   ```
   This declares all four route groups as explicit Stack screens. The `(scan)` group gets `presentation: "modal"` so it overlays the tabs. All groups get `headerShown: false` to let each group control its own header.

2. Create `app/(tabs)/_layout.tsx` — Headless Tabs with auth redirect:
   - Import `Tabs`, `TabList`, `TabTrigger`, `TabSlot` from `expo-router/ui`
   - Import `Redirect` from `expo-router`
   - Import `useSession` from `@/features/auth/session`
   - Import `useBreakpoint` from `@/lib/hooks/useBreakpoint`
   - Import `View`, `Text` from `react-native`

   Auth guard: if `isLoading`, return `null`. If `!session`, return `<Redirect href="/(auth)/login" />`.

   Layout structure:
   - Root: `<Tabs>` with `style={{ flex: 1, flexDirection: isWeb ? 'row' : 'column' }}`
   - Hidden `<TabList>` with `style={{ height: 0, overflow: 'hidden', position: 'absolute' }}` containing 5 `TabTrigger` entries:
     - `<TabTrigger name="index" href="/" />`
     - `<TabTrigger name="my-recipes" href="/my-recipes" />`

     - `<TabTrigger name="family" href="/family" />`
