Rebuild `app/(tabs)/recipes/index.tsx` to match cookbook.pen spec. Preserve search/filter business logic but completely redo layout and styling.

**Data loading:**
- Use existing `searchRecipes(filters)` for recipe data. Maintain the existing search/filter state pattern (query, tags, visibility, family_id).
- After recipes load, call `getRecipeThumbnailUrlMap(recipeIds, 300)` once for all recipes. Store in `thumbnailByRecipeId` state.
- Re-fetch thumbnails when recipe list changes.
- Use `useFocusEffect` from `@react-navigation/native` to reload on screen focus (existing pattern).

**Layout:**
- Wrap in `<PageContainer>` (default variant)
- Screen title "My Recipes" rendered as a View at top: fontSize2xl, fontFamilyDisplay, textPrimary.

**Search bar:**
- TextInput with borderDefault border, radiusMd, bgCard background, fontFamilyBody placeholder "Search recipes..."
- Search icon (lucide Search) inside the input area
- onChange updates search query state, which triggers searchRecipes re-query

**Filter section (preserve existing):**
- Collapsible filter area with tag chips, visibility toggle, family filter
- Style filter chips with tokens: bgCard background, borderDefault border, radiusPill, fontSizeSm
- Active filter chip: accentBlue background, white text
- "Clear all" link in accentBlue

**Responsive Grid:**
- `const numColumns = breakpoint === 'mobile' ? 1 : breakpoint === 'tablet' ? 2 : 3;`
- FlatList with:
  - `numColumns={numColumns}`
  - `key={numColumns}` (CRITICAL: forces remount on column change)
  - `keyExtractor={(item) => item.id}`
  - `contentContainerStyle={{ padding: 20, gap: 16 }}` (use PADDING_BY_BREAKPOINT for padding)
  - `columnWrapperStyle={numColumns > 1 ? { gap: 16 } : undefined}`
  - `renderItem`: Render `<RecipeCard recipe={item} thumbnailUrl={thumbnailByRecipeId[item.id]} onPress={() => router.push(\`/recipes/${item.id}\`)} style={{ flex: 1 }} />`
  - On web: use `contentContainerStyle={{ flexGrow: 1 }}` to prevent FlatList collapse

**Empty state:**
- When no recipes match filters: "No recipes found" message centered with textSecondary
- When user has no recipes at all: "Create your first recipe" with a Pressable linking to `/recipes/create`, styled with accentBlue

**Loading state:**
- ActivityIndicator centered during initial load
- No loading indicator during search re-queries (show stale data until new data arrives)

**"Create Recipe" FAB or button:**
- Pressable "+" or "Create Recipe" button at top-right near the title. Navigates to `/recipes/create`.
- Style: accentBlue background, white text/icon, radiusMd

**Anti-patterns to avoid:**
- Do NOT use `flex: 1` on FlatList inside flex containers on web -- use `flexGrow: 1, flexBasis: 0`
- Do NOT omit `key={numColumns}` on FlatList
- Do NOT fetch thumbnails per-card in renderItem
- Do NOT use StyleSheet.create for breakpoint-dependent values
- Do NOT use hardcoded hex colors
