Create two `_layout.tsx` files mirroring the pattern from `app/(tabs)/family/_layout.tsx`.

**app/(tabs)/recipes/_layout.tsx:**
- Import `Stack` from `expo-router`
- Export default `RecipesLayout` function
- Return `<Stack screenOptions={{ headerShown: false }} />`
- Use `headerShown: false` (NOT `headerTitle`) because the recipe screens manage their own headers (recipe detail has a custom sticky header with back arrow and Start Cooking button; recipe list has its own title row). The family tab uses `headerTitle` which shows the default expo-router header, but recipe screens already have custom header UI and showing a double header would be wrong.

**app/(tabs)/collections/_layout.tsx:**
- Import `Stack` from `expo-router`
- Export default `CollectionsLayout` function
- Return `<Stack screenOptions={{ headerShown: false }} />`
- Same reasoning: collections screens should manage their own headers for consistency with the recipes pattern.

Both files should be under 15 lines each. Do NOT add any screen-specific options — the default Stack with hidden headers is all that's needed. The Stack simply provides the navigation container that `router.push()` needs to push sub-routes onto.
