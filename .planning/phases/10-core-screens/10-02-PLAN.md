  <action>
Rebuild `app/(tabs)/recipes/[id].tsx` from scratch. Preserve all existing business logic (data loading, delete, collection management, rating, photo gallery) but completely redo the layout and styling to match cookbook.pen spec.

**Overall structure:**
```
<View style={{ flex: 1 }}>
  {/* Sticky action header -- ABOVE ScrollView, not inside it */}
  <ActionHeader />
  {/* Scrollable content */}
  <ScrollView style={{ flex: 1 }}>
    {/* Responsive layout wrapper */}
  </ScrollView>
</View>
```

**Sticky Action Header (outside ScrollView):**
- flexDirection: 'row', justifyContent: 'space-between', padding: 16
- borderBottomWidth: 1, borderBottomColor: borderDefault, backgroundColor: bgPage
- Left: Back button (ChevronLeft from lucide-react-native, onPress: router.back())
- Right: Row of action buttons:
  - Edit button (only if session.user.id === recipe.owner_user_id): navigates to `/recipes/${id}/edit`
  - Start Cooking button: styled prominently with accentBlue background, white text, radiusMd. Navigates to `/recipes/${id}/cook` via router.push.
- Use tokens for all colors and fonts.

**Hero Image (mobile: full-width, tablet/web: constrained):**
- If photos exist: show first photo full-width on mobile, max 500px height. Use `getPhotoUrl()`.
- If no photos: show #E8E0D8 placeholder (200px height) with UtensilsCrossed icon.
- On tablet/web: image is in the left column of the two-column layout.

**Responsive Two-Column Layout (tablet/web only):**
- Use `useBreakpoint()` to detect. `const isWideLayout = breakpoint === 'tablet' || breakpoint === 'web';`
- Wide: `flexDirection: 'row', gap: 32`. Left column (flex: 1): hero image + photo gallery. Right column (flex: 1): recipe info content.
- Mobile: single column, everything stacked vertically.

**Content Sections (in order per .pen spec):**
1. **Title + metadata:** Title in fontSize2xl, fontFamilyDisplay, textPrimary. Below: visibility badge pill (same style as RecipeCard). Below: time + servings in textSecondary.
2. **Description:** If present, fontSizeBase, fontFamilyBody, textSecondary.
3. **Ingredients section:** Section header "Ingredients" (fontSizeLg, fontFamilyDisplay). List each ingredient using `displayAmount()` for unit conversion. Use borderSubtle bottom borders between items. Ingredients are NOT checkable per user decision.
4. **Steps section:** Section header "Steps". Numbered steps with step number badge (accentBlue circle with white text) + step text. Gap between steps.
5. **Story section:** If `source_story` present, section header "The Story Behind This Recipe" + story text in fontFamilyBody, textSecondary, fontStyle: 'italic'.
6. **Ratings section:** Section header "Ratings". Display StarRating in read-only mode showing `recipe.rating_average` with count text "{rating_count} ratings". Below: interactive StarRating for current user's rating with `onChange` handler calling `upsertRating()`.
7. **Comments section:** Section header "Comments". Render `<CommentThread recipeId={id} userId={session?.user?.id} />` and `<CommentInput recipeId={id} userId={session?.user?.id} />`.

**Collection Picker (existing functionality):**
- Preserve the existing collection picker overlay/modal logic. Style it with tokens (bgPage, borderDefault, radiusMd).
- Trigger via an "Add to Collection" button in the action header or below the title area.

**Photo Gallery (existing functionality):**
- If multiple photos exist, show a horizontal FlatList below the hero image (on mobile) or in the left column (on tablet/web).
- Use `getPhotoUrl()` for URLs. Owner can delete photos (existing deleteRecipePhoto API).
- Style thumbnails with radiusSm, 80x80px.

**Loading/Error states:**
- Loading: ActivityIndicator centered
- Error: textSecondary error message with "Retry" button
- Recipe not found: "Recipe not found" message

**Anti-patterns to avoid:**
- Do NOT use `Dimensions.get('window')` (existing code uses this on line ~712) -- use useBreakpoint()
- Do NOT use StyleSheet.create for breakpoint-dependent values
- Do NOT use hardcoded hex colors -- all from tokens.ts
- Do NOT use `position: 'fixed'` -- action header is above ScrollView, not fixed-positioned
- Do NOT use `Stack.Screen options={{ title }}` -- render title in screen content instead (TabSlot layout may suppress Stack headers)
