    **Step 1 — Install packages:**
    Run `npx expo install @expo-google-fonts/bricolage-grotesque @expo-google-fonts/dm-sans expo-splash-screen`

    This installs the three new packages. `expo-font` is already a transitive dependency of expo SDK 54 but verify it appears in package.json after install — if not, also run `npx expo install expo-font`.

    **Step 2 — Update app/_layout.tsx:**
    Modify the existing root layout to add font loading with splash screen hold. Preserve the existing SessionProvider and Stack structure.

    The updated file must:
    1. Call `SplashScreen.preventAutoHideAsync()` at MODULE LEVEL (outside the component function, before any React code runs). This is critical — calling it inside useEffect is too late and causes FOUT.
    2. Import font variants: BricolageGrotesque_400Regular, BricolageGrotesque_600SemiBold, BricolageGrotesque_700Bold from `@expo-google-fonts/bricolage-grotesque`, and DMSans_400Regular, DMSans_500Medium, DMSans_700Bold from `@expo-google-fonts/dm-sans`
    3. Use `useFonts` hook (from `expo-font` directly — this works with fonts from multiple packages) to load all 6 font variants in a single call
    4. In a `useEffect`, call `SplashScreen.hideAsync()` when `fontsLoaded || fontError` is true
    5. Return `null` while fonts are loading (`!fontsLoaded && !fontError`) to keep splash visible
    6. When ready, render the existing `<SessionProvider><Stack ...></SessionProvider>` tree unchanged

    **Anti-patterns to avoid (from RESEARCH.md):**
    - Do NOT call `SplashScreen.preventAutoHideAsync()` inside useEffect or the component body — must be module level
    - Do NOT use `AppLoading` (deprecated since SDK 49)
    - Do NOT import `useFonts` from two separate package hooks and call both — use one `useFonts` call from `expo-font`
    - Do NOT use `Dimensions.get` anywhere in this file

    **Font variant selection rationale:** Loading 6 variants (3 Bricolage + 3 DM Sans) covers display headings (regular, semibold, bold) and body text (regular, medium, bold). This matches the RESEARCH.md recommended starting set. Additional variants can be added later if .pen analysis reveals other weights in use.
