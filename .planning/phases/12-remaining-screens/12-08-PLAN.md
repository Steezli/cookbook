Create a new migration file that fixes three database issues:

1. **Add FK from family_memberships.user_id to profiles.user_id:** PostgREST resolves embedded resources via FK relationships. The current FK goes to auth.users(id), but PostgREST cannot see into the auth schema. Add a SECOND FK constraint pointing to public.profiles(user_id) so PostgREST can resolve `profiles(email, display_name)` in queries.

```sql
-- Add FK to profiles so PostgREST can resolve profiles() embedded joins
ALTER TABLE family_memberships
  ADD CONSTRAINT family_memberships_profile_fk
  FOREIGN KEY (user_id) REFERENCES profiles(user_id) ON DELETE CASCADE;
```

Note: This adds a second FK on user_id. The existing FK to auth.users remains for referential integrity. The new FK to profiles enables PostgREST embedding. This is a standard pattern for Supabase apps.

```typescript
import { Platform } from 'react-native';

// Helper function at module level or inside component:
function confirmAction(title: string, message: string, onConfirm: () => void) {
  if (Platform.OS === 'web') {
    if (window.confirm(`${title}\n\n${message}`)) {
      onConfirm();
    }
  } else {
    Alert.alert(title, message, [
      { text: 'Cancel', style: 'cancel' },
      { text: 'Confirm', style: 'destructive', onPress: onConfirm },
    ]);
  }
}
```
