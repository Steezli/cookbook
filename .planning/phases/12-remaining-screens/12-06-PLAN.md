  <action>
Replace all `supabase.auth.getUser()` calls with `supabase.auth.getSession()` in scan-service.ts. There are 4 occurrences at lines ~38, ~70, ~111, and ~211.

For each occurrence, change the pattern from:
```
const { data: { user } } = await supabase.auth.getUser();
if (!user) throw new Error('Not authenticated');
```
to:
```
const { data: { session } } = await supabase.auth.getSession();
if (!session?.user) throw new Error('Not authenticated');
const user = session.user;
```

This preserves the `user` variable so the rest of each function body works unchanged. The key difference: getSession() reads the locally cached session (fast, works with expired access tokens because the SDK auto-refreshes), while getUser() makes a server call that fails when the access token is expired.

Do NOT touch the no-op lock shim in supabase.ts -- that is a separate concern.

<task type="auto">
  <name>Task 2: Fix sign-out double navigation flash on iOS</name>
  <files>app/(tabs)/profile.tsx, app/(auth)/logout.tsx</files>
  <action>
Two changes to eliminate the double render flash:

1. **profile.tsx handleSignOut (lines 158-168):** Remove the explicit `router.replace("/(auth)/login")` call after `supabase.auth.signOut()`. The reactive `<Redirect href="/(auth)/login" />` in `(tabs)/_layout.tsx` (line 21) already handles navigation when session becomes null. Having both causes two rapid navigations on iOS native, producing a visible flash. The function should become:

```typescript
async function handleSignOut() {
  try {
    await supabase.auth.signOut();
    // Reactive redirect in _layout.tsx handles navigation when session becomes null
  } catch (e) {
    Alert.alert(
      "Error",
      e instanceof Error ? e.message : "Failed to sign out"
    );
  }
}
```

2. **logout.tsx (line 22):** Change `router.replace("/")` to `router.replace("/(auth)/login")` for consistency. The "/" route redirects to /(public) via index.tsx, which is wrong for a sign-out flow. However, also consider: since the reactive redirect in _layout.tsx handles this, the explicit navigation in logout.tsx may also be redundant. Apply the same pattern: remove the explicit `router.replace` from the `finally` block entirely, letting the reactive redirect handle it. If logout.tsx still needs to show "Logging out..." text while the signOut completes, keep the component but remove the finally navigation.

IMPORTANT: Do NOT modify `app/(tabs)/_layout.tsx`. The reactive `<Redirect href="/(auth)/login" />` on line 21 must remain intact -- it is the single navigation path that replaces the removed explicit navigations.
