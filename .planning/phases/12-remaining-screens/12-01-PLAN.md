  <files>src/features/auth/social-auth.ts</files>
  <action>
Install new dependencies:
```bash
npx expo install expo-auth-session expo-apple-authentication expo-clipboard expo-web-browser
```

Create `src/features/auth/social-auth.ts` with three exported functions:

1. `signInWithGoogle()` — Uses `supabase.auth.signInWithOAuth({ provider: 'google' })` with `AuthSession.makeRedirectUri({ path: 'auth/callback' })` as redirectTo. On native, opens result URL with `WebBrowser.openAuthSessionAsync`. On web, Supabase handles redirect automatically.

2. `signInWithApple()` — On iOS (`Platform.OS === 'ios'`), uses `AppleAuthentication.signInAsync` to get native credential, then `supabase.auth.signInWithIdToken({ provider: 'apple', token: credential.identityToken })`. On non-iOS, falls back to `signInWithOAuth({ provider: 'apple' })` same pattern as Google.

3. `signInWithFacebook()` — Same pattern as Google but with `provider: 'facebook'`.

4. `isAppleNativeAvailable()` — Returns `Platform.OS === 'ios'` check for conditional Apple button rendering.

All functions return `{ data, error }` from Supabase auth. Import supabase from `@/lib/supabase`.
  </action>
