**DraftReview component (`src/features/scans/DraftReview.tsx`):**
This is the main rebuild. Preserve ALL existing draft data fetching and editing logic. The key changes are:

1. **Actual photo display (replacing placeholder):**
   - Fetch the scan job's photo URL(s) using `getJobPhotos(jobId)` from `src/features/scan/scan-service.ts` which returns storage paths
   - Convert storage paths to displayable URLs using `getScanPhotoUrl(storagePath)` from `src/features/scan/scan-photos.ts`
   - Display using React Native `Image` component
   - For multi-photo: show a horizontal scrollable gallery (ScrollView horizontal) with thumbnails below main photo

2. **Mobile layout (collapsible photo):**
   - Photo starts visible at top (~300px height)
   - Use `Animated.Value` driven by ScrollView `onScroll` to interpolate photo height
   - `scrollY.interpolate({ inputRange: [0, 200], outputRange: [300, 60], extrapolate: 'clamp' })`
   - At collapsed state (60px): photo shows as thumbnail strip
   - Draft fields (title, ingredients, steps, etc.) scroll below
   - Use `Animated.event([{ nativeEvent: { contentOffset: { y: scrollY } } }])` with `useNativeDriver: false` (height animation can't use native driver)

3. **Tablet/Web layout (side-by-side):**
   - flexDirection: 'row'
   - Left panel (~40% width): photo(s) displayed full height, sticky/scrollable
   - Right panel (~60% width): draft fields in ScrollView
   - Photo panel has fixed position within its column (not RN position:fixed — use flex layout where left panel doesn't scroll)

4. **Common elements:**
   - Draft fields: title, description, ingredients list, steps list, cooking time, servings
   - "Edit" button to switch to DraftEditor
   - "Save as Recipe" button (accentBlue, prominent)
   - "Discard Draft" button (destructive, textDanger color)
   - All tokens, fontFamily, colors from tokens.ts

useBreakpoint() to switch between mobile (collapsible) and tablet/web (side-by-side) layouts.
