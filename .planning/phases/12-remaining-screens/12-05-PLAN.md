Full rebuild of profile.tsx to match cookbook.pen. This is a net-new screen design from Phase 8.

Per CONTEXT.md locked decision: single scrollable page with avatar, display name, email, unit preference, logout.

**Layout:**
- PageContainer wrapper
- useBreakpoint() for responsive layout
- Mobile: full-width, padding 24, sections stack vertically
- Tablet: centered content with maxWidth ~600
- Web: centered content with maxWidth ~600 (settings pages don't need multi-column)

**Avatar section (top):**
- Large circular avatar (80-100px) with user initials as fallback
- Initials derived from display_name: first letter of first name + first letter of last name, uppercase
- Background: accentWarm or similar warm color from tokens
- Text: white, fontFamilyDisplay, bold
- Note: Avatar image upload is a research open question (profiles table may not have avatar_url column). Implement initials-only for now. If cookbook.pen shows an upload button, add a placeholder Pressable that shows "Coming soon" alert.

**Profile info section:**
- Display name: editable field (TextInput with "Edit" pencil icon toggle)
  - When not editing: show as text with pencil icon Pressable to enable edit
  - When editing: TextInput with Save/Cancel buttons
  - On save: update profiles table via `supabase.from('profiles').update({ display_name }).eq('id', user.id)`
- Email: display-only (greyed out, not editable — email changes go through Supabase auth flow)
- Section styled with bgCard background, radiusMd, padding 16, shadowSm

**Preferences section:**
- Unit preference toggle: "Metric" / "Imperial" using segmented control or toggle buttons
  - Two Pressable buttons side by side, selected one has accentBlue bg + white text, unselected has bgCard + textSecondary
  - On change: update profiles table `supabase.from('profiles').update({ unit_preference }).eq('id', user.id)`
  - Load current preference on mount from profiles table
- Section styled same as profile info section

**Account section:**
- "Sign Out" button: full-width, destructive style (textDanger color, borderColor borderDefault)
  - Calls `supabase.auth.signOut()` then navigates to auth
- Separated from other sections with more vertical spacing

**Data fetching:**
- On mount: fetch user profile from `supabase.from('profiles').select('*').eq('id', session.user.id).single()`
- Use useSession() to get current session/user
- Loading state: ActivityIndicator while fetching profile
- Error state: "Failed to load profile" with retry button

All tokens (colors, fonts, radii, shadows). No hardcoded hex values. No StyleSheet.create for breakpoint styles. Pressable not TouchableOpacity.
