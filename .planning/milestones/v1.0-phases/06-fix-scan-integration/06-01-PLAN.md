<objective>
Fix all service-layer bugs in the scan-to-recipe flow: auth wiring (getCurrentUserId), user filtering (getUserScanJobs), retry mechanism (retryScanJob), recipe conversion (convertToRecipe column names), confidence mapping (mapScoreToStatus inversion), and Supabase client singleton usage.

Purpose: These 6 service-layer bugs prevent the entire scan flow from working. Auth returns null so real-time updates never fire. Retry nests a Promise as a value. convertToRecipe uses 4 wrong column names. mapScoreToStatus is inverted. The draft service creates its own Supabase client bypassing auth state.

Output: Fixed scan-service.ts and scan-draft-service.ts with passing unit tests.
</objective>
