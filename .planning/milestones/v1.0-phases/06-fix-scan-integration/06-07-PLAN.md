<objective>
Fix the Save as Recipe and Discard dialogs in DraftManager.tsx so they appear as visible modal overlays instead of rendering invisibly inline.

Purpose: Both dialogs use Tailwind CSS class names (e.g., `className="fixed inset-0 z-50"`) for layout and overlay positioning. Tailwind CSS is NOT installed in this project, so these classes have no effect — the dialogs render at the bottom of the scroll container, invisible to the user. This is the same class of bug fixed in plan 06-06 (scroll fix). The fix is identical in approach: replace every `className` on the dialog overlay `<div>` elements with inline `style` objects.

Output: Both dialogs are visible, functional modal overlays. Users can convert drafts to recipes and discard drafts.
</objective>
