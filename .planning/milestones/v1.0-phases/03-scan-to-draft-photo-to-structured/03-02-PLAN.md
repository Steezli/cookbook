# Phase 3 Plan 2: SCAN-02 - OCR Service Integration & Structured Extraction

## Objective
Integrate Google Cloud Vision API for OCR text extraction and AI-powered structured recipe data parsing. Extract ingredients, steps, and units from recipe photos while preserving raw text for user reference.

## Context Files
- `.planning/phases/03-scan-to-draft-photo-to-structured/03-CONTEXT.md`

## Tasks

### Task 1: Google Cloud Vision API Integration
- **type:** auto
- **behavior:**
  - Set up Google Cloud Vision API client credentials
  - Create OCR service for text extraction from photos
  - Implement error handling for API failures and rate limits
  - Add logging for OCR requests and responses
  - Handle different image formats and orientations
- **done:** OCR service successfully extracts text from recipe photos

### Task 2: Structured Recipe Data Parsing
- **type:** auto
- **behavior:**
  - Create AI service for parsing OCR text into structured recipe data
  - Extract ingredients with quantities, units, and preparation notes
  - Parse cooking steps with chronological ordering
  - Identify recipe metadata (title, servings, prep/cook time)
  - Handle common OCR errors and ambiguous text
- **done:** OCR text converted to structured recipe format

### Task 3: Confidence Scoring System
- **type:** auto
- **behavior:**
  - Implement confidence scoring for each extracted field
  - Calculate overall recipe confidence based on field quality
  - Flag low-confidence ingredients and steps for user review
  - Add AI assistance for enhancing low-confidence fields
  - Store confidence scores in scan_drafts table
- **done:** Confidence indicators guide user review priorities

### Task 4: Scan Draft Creation
- **type:** auto
- **behavior:**
  - Complete `scan_drafts` table implementation
  - Store structured recipe data with confidence scores
  - Preserve raw OCR text for user reference
  - Link drafts to original scan jobs and photos
  - Add draft status workflow (ready/needs_review/enhanced)
- **done:** Drafts contain both structured data and raw text

## Verification
1. Google Cloud Vision API successfully extracts text from various recipe photo formats
2. Structured parsing correctly identifies ingredients, steps, and metadata
3. Confidence scoring accurately reflects extraction quality
4. Low-confidence items are properly flagged for user review
5. Raw OCR text is preserved and accessible for reference
6. Error handling gracefully manages API failures and rate limits

## Success Criteria
1. A scan produces a structured draft (ingredients/steps/units) and preserves raw extracted text
2. OCR accuracy meets minimum quality threshold for handwritten recipes
3. Structured parsing handles common recipe formats and layouts
4. Confidence scores provide meaningful guidance for user review
5. Error recovery prevents data loss and enables retry attempts

## Output Specification
- Google Cloud Vision API integration service
- AI-powered structured recipe parsing system
- Confidence scoring algorithm and indicators
- Complete scan_drafts table and related database operations
- Error handling and retry mechanisms for OCR failures
