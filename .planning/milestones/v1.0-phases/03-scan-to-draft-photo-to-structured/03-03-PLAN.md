# Phase 3 Plan 3: SCAN-03 - Draft Editing Interface with Confidence Indicators

## Objective
Create an intuitive draft editing interface that allows users to review, correct, and enhance AI-extracted recipe data. Show confidence indicators to prioritize review efforts and provide AI assistance for common corrections.

## Context Files
- `.planning/phases/03-scan-to-draft-photo-to-structured/03-CONTEXT.md`

## Tasks

### Task 1: Draft Review Interface
- **type:** auto
- **behavior:**
  - Create draft review page layout with side-by-side comparison
  - Display original photo alongside extracted text
  - Show structured recipe fields (ingredients, steps, metadata)
  - Add confidence indicators for each field (color-coded)
  - Implement responsive design for mobile and desktop
- **done:** Users can see extracted data with confidence indicators

### Task 2: Field Editing Controls
- **type:** auto
- **behavior:**
  - Make all recipe fields editable with proper input types
  - Add ingredient-specific editing (quantity, unit, name, prep notes)
  - Create step editing with reordering capabilities
  - Implement auto-save for draft changes
  - Add undo/redo functionality for user corrections
- **done:** Users can edit all extracted recipe fields easily

### Task 3: AI-Assisted Corrections
- **type:** auto
- **behavior:**
  - Add "Fix with AI" buttons for low-confidence fields
  - Implement unit normalization and conversion suggestions
  - Create ingredient splitting and combination tools
  - Add step clarification and rephrasing assistance
  - Provide quick-fix suggestions for common OCR errors
- **done:** AI tools help users quickly correct common issues

### Task 4: Draft Management Actions
- **type:** auto
- **behavior:**
  - Implement "Save as Recipe" conversion from draft to published recipe
  - Add "Save as Draft" for preserving incomplete work
  - Create "Discard Draft" option with confirmation
  - Add "Share Draft" for family collaboration (future feature)
  - Implement draft versioning to track changes
- **done:** Users can manage draft lifecycle effectively

## Verification
1. Draft review interface displays all extracted data clearly
2. Confidence indicators accurately guide user attention
3. Field editing works smoothly with proper input validation
4. AI assistance provides helpful corrections without overwriting
5. Draft management actions work as expected
6. Auto-save prevents data loss during editing
7. Mobile interface is fully functional and usable

## Success Criteria
1. User can correct any extracted field before saving as normal recipe
2. Confidence indicators prioritize review efforts effectively
3. AI assistance reduces correction time for common issues
4. Draft editing maintains data integrity and prevents loss
5. Interface is intuitive for "Grandma-friendly" usability

## Output Specification
- React components for draft review and editing interface
- Confidence indicator UI components with color coding
- AI assistance tools and integration services
- Draft management API endpoints and business logic
- Mobile-responsive design implementation
