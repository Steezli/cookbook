    - convertWeight(1, 'lb', 'g') -> ~453.592

    - displayAmount(2, 'cup', 'metric', '2 cups flour') -> "473.18 ml (2 cup) flour" or similar
    - displayAmount(500, 'ml', 'imperial', '500ml flour') -> "2.11 cup (500 ml) flour" or similar

    - canConvert('cup') -> true
    - canConvert('pinch') -> false

    - formatAmount(3.00) -> '3'

    **Parser behavior:**
    - parseIngredient('2 cups flour') -> { amount: 2, unit: 'cups', ingredient: 'flour', original: '2 cups flour', isAmbiguous: false }
    - parseIngredient('1/2 tsp salt') -> { amount: 0.5, unit: 'tsp', ingredient: 'salt', original: '1/2 tsp salt', isAmbiguous: false }
    - parseIngredient('1 1/2 tbsp butter') -> { amount: 1.5, unit: 'tbsp', ingredient: 'butter', ... }
    - parseIngredient('a pinch of salt') -> { amount: null, unit: null, ingredient: 'a pinch of salt', isAmbiguous: true }
    - parseIngredient('handful of herbs') -> { amount: null, unit: null, ingredient: 'handful of herbs', isAmbiguous: true }
    - parseIngredient('3 eggs') -> { amount: 3, unit: null, ingredient: 'eggs', ... } (number but no unit)
    - parseIngredient('flour') -> { amount: null, unit: null, ingredient: 'flour', isAmbiguous: false }

    - parseIngredient('1½ cups milk') -> { amount: 1.5, unit: 'cups', ingredient: 'milk', ... } (number + Unicode fraction)

  <implementation>
    **Types (src/features/units/types.ts):**
    - UnitSystem = 'metric' | 'imperial'
    - ParsedIngredient = { amount: number | null, unit: string | null, ingredient: string, original: string, isAmbiguous: boolean }
    - EnhancedIngredient = { text: string, sort_order: number, amount: number | null, unit: string | null, original_text: string | null, is_ambiguous: boolean }

    **Conversions (src/features/units/conversions.ts):**
    - VOLUME_TO_ML lookup table with US customary (tsp, tbsp, fl oz, cup, pint, quart, gallon) and metric (ml, l) plus common aliases
    - WEIGHT_TO_GRAMS lookup table with oz, lb, g, kg plus common aliases
    - IMPERIAL_VOLUME_PREFERRED and METRIC_VOLUME_PREFERRED maps for choosing the best target unit based on magnitude
    - convertVolume(amount, fromUnit, toUnit): number — converts via ml intermediate
    - convertWeight(amount, fromUnit, toUnit): number — converts via grams intermediate
    - canConvert(unit): boolean — checks if unit exists in either lookup
    - getTargetUnit(unit, preference): string — returns best display unit for given preference
    - formatAmount(num): string — rounds to 2 decimal places, strips trailing zeros
    - displayAmount(amount, unit, preference, originalText): string — formats as "converted target (original amount unit)" per locked decision. When preference matches the stored unit system, show just "amount unit" without conversion.

    **Parser (src/features/units/parser.ts):**
    - FRACTION_MAP: 15 common Unicode fractions mapped to decimals
    - AMBIGUOUS_TERMS: ['pinch', 'dash', 'handful', 'bunch', 'sprig', 'to taste', 'some', 'dollop', 'smidgen', 'sprinkle']
    - KNOWN_UNITS regex pattern matching tsp, tbsp, cup, cups, tablespoon(s), teaspoon(s), oz, ounce(s), fl oz, ml, l, liter(s), g, gram(s), kg, lb, pound(s)
    - parseIngredient(text): ParsedIngredient — parses [amount] [unit] [ingredient] format
      1. Check for ambiguous terms first
      2. Extract Unicode fraction at start
      3. Extract whole/decimal number
      4. Extract slash fraction (1/2, 3/4)
      5. Extract known unit
      6. Remainder is ingredient name

    **Test setup:** Ensure jest or vitest is configured. Check existing test config in project. If none exists, add minimal jest config compatible with the Expo TypeScript setup.
