  <action>
The recipe detail screen only fetches data on mount via `useEffect([id])` (lines 53-55). When returning from edit screen via `router.back()`, the component doesn't remount, so stale data shows.

Fix approach:
1. Import `useFocusEffect` from `@react-navigation/native`
2. Replace or supplement the existing `useEffect` with `useFocusEffect` to refetch recipe data when the screen gains focus

Specific changes to `app/recipes/[id].tsx`:

Add import:
```typescript
import { useFocusEffect } from "@react-navigation/native";
import { useCallback } from "react";
```

Replace the recipe loading useEffect (lines 53-55):
```typescript
useFocusEffect(
  useCallback(() => {
    void loadRecipe();
  }, [id])
);
```

This ensures `loadRecipe()` is called every time the screen comes into focus, not just on mount.

  <action>
The photo gallery uses `resizeMode="cover"` (line 190) which crops images to fit the container. Users report images display in "odd formats" compared to originals.

Current code (lines 498-507):
```typescript
photoContainer: {
  width: Dimensions.get("window").width * 0.7,
  height: 250,
  ...
},
photo: {
  width: "100%",
  height: "100%",
  borderRadius: 12
},
```

Fix approach - change to `contain` to preserve aspect ratio:
1. Change `resizeMode="cover"` to `resizeMode="contain"` on line 190
2. Add a background color to the photo container so letterboxing looks intentional:
   ```typescript
   photoContainer: {
     width: Dimensions.get("window").width * 0.7,
     height: 250,
     marginRight: 12,
     position: "relative",
     backgroundColor: "#f0f0f0",  // Add this for letterbox background
     borderRadius: 12,
     overflow: "hidden"
   },
   ```

Alternative approach - use aspectRatio:
If we want images to show at their natural aspect ratio, we could remove the fixed height and use `aspectRatio: 4/3` or similar, but this may cause layout jumps.

Recommended: Use `contain` with a subtle background - this preserves the image while maintaining consistent gallery sizing.
