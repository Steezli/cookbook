<task type="auto">
  <name>Task 1: Convert DraftReview.tsx to React Native components</name>
  <files>src/features/scans/DraftReview.tsx</files>
  <action>
Rewrite DraftReview.tsx replacing ALL web HTML elements and Tailwind className with React Native components and StyleSheet. The business logic (useEffect, state, service calls) stays identical -- only the JSX rendering layer changes.

**Imports to change:**
- Remove the standalone `import { Text } from "react-native"` (leftover)
- Add: `import { View, Text, ScrollView, TouchableOpacity, ActivityIndicator, StyleSheet } from 'react-native'`
- Add: `import { router } from 'expo-router'`

**Element conversions (every instance):**
- `<div>` -> `<View>`
- `<span>` -> `<Text>`
- `<p>` -> `<Text>`
- `<h1>`, `<h2>`, `<h3>` -> `<Text style={styles.headingN}>`
- `<button onClick={fn}>` -> `<TouchableOpacity onPress={fn}><Text>...</Text></TouchableOpacity>`
- `<pre>` -> `<Text style={styles.monospace}>`
- All `className="..."` -> `style={styles.xxx}` using StyleSheet.create

**Specific fixes:**
- `window.history.back()` on line 362 -> `router.back()`
- `getConfidenceColor()` currently returns Tailwind class strings -> change to return `{ bg: string, text: string }` style objects using the color mapping from research (green: bg #dcfce7 text #166534, yellow: bg #fef9c3 text #854d0e, red: bg #fef2f2 text #991b1b)
- ConfidenceIndicator sub-component: convert from div/span with className to View/Text with dynamic style
- Loading states: replace the `animate-pulse` skeleton divs with `<ActivityIndicator size="large" color="#3b82f6" />` centered in container
- Auth required state: View with yellow warning card (backgroundColor: '#fefce8', borderColor: '#fde68a')
- Error state: View with red error card (backgroundColor: '#fef2f2', borderColor: '#fca5a5')

**Layout structure:**
- Outer container: `<ScrollView style={styles.container} contentContainerStyle={styles.contentContainer}>`
- The `grid grid-cols-1 lg:grid-cols-2 gap-6` -> single column View (mobile-first, no grid needed on native)
- Card sections: `<View style={styles.card}>` with white background, border, borderRadius, shadow
- `max-h-48 overflow-y-auto` on ingredient/instruction lists -> just a View (parent ScrollView handles scrolling, avoid nested ScrollView)

**StyleSheet.create():**
Use colors from existing scan hub: background #f3f4f6, cardBg #ffffff, textPrimary #111827, textSecondary #6b7280, border #e5e7eb, blue #3b82f6. Follow the styling patterns from app/(scan)/index.tsx (borderRadius: 12, padding: 20, shadow properties, elevation).

**Do NOT:**
- Change any business logic, state management, or service calls
- Use className anywhere
- Use any web HTML elements (div, span, button, input, textarea, pre)
- Use inline style objects for static styles (always StyleSheet.create)
