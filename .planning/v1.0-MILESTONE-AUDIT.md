## Cross-Phase Integration Issues

### P1 — Native Crashes (Blocking for iOS/Android)

1. **DraftReview.tsx / DraftEditor.tsx → React Native runtime**
   Both files use web-only HTML elements (`<div>`, `<span>`, `<input>`, `<textarea>`, `<button>`, `<pre>`, `<h1>`–`<h3>`) and Tailwind `className`. These will crash with "div is not a valid React Native component" on iOS/Android.
   Affected: SCAN-03, SCAN-04

2. **DraftReview.tsx → expo-router navigation**
   "Back to Scans" button uses `window.history.back()` which doesn't exist on native. Must use `router.back()`.
   Affected: SCAN-03

### P2 — Missing Navigation (Blocking Discoverability)

3. **app/index.tsx → app/recipes/index.tsx**
   No link to `/recipes` from home screen for authenticated users. The recipe list and all downstream features (create, view, edit, search, collections, comments, ratings) are undiscoverable without typing the URL.
   Affected: REC-01..05, COLL-01..02, SRCH-01..02

### P3 — Functional Gaps (Degraded UX)

4. **DraftReview.tsx — photo display stub**
   Original scan photo is never loaded; renders placeholder "Original photo would be displayed here."
   Affected: SCAN-03

5. **ScanPhotoUpload — missing onUploadComplete callback**
   No explicit list refresh after photo upload (real-time subscription fires but no immediate feedback).
   Affected: SCAN-01

### P4 — Dead Code / Tech Debt

6. `src/features/scan/scan-service.ts`: Orphaned `ScanDraft` type with invalid status values and unused `getScanDraft` function
7. `app/(scan)/index.tsx`: Dead "Review Draft" button with `TODO` comment — navigation works via `ScanJobList` instead
